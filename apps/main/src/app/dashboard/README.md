# Dashboard

Main dashboard area containing various dashboard-related routes and pages.

## Structure

This folder contains subdirectories for different dashboard sections:
- `activity/` - Activity-related dashboard pages
- `core/` - Core dashboard functionality
- `partials/` - Partial dashboard views
- `product/` - Product-related dashboard pages
- `workspaces/` - Workspace management
- `help/` - Help and support pages
