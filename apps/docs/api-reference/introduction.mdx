## Overview

The Pacepard API provides a complete platform for managing innovation ecosystems including:

- **Authentication & Users**: User registration, login, role management, and onboarding
- **Workspaces**: Collaborative environments for teams and organizations
- **Hackathons**: Event management with entries, teams, and judging
- **Projects**: Project management with tasks, teams, and collaboration
- **Payments**: Subscription plans and payment processing
- **Storage**: File upload and management
- **Webhooks**: Payment notifications and integrations

## Getting Started

1. **Authentication**: All API endpoints require Bearer token authentication
2. **Base URL**: `https://api.pacepard.com`
3. **Content Type**: All requests use `application/json` unless specified otherwise
4. **Rate Limiting**: Standard rate limits apply to all endpoints

## Authentication

All API endpoints are authenticated using Bearer tokens. Include the token in the Authorization header:

```bash
Authorization: Bearer <your-jwt-token>
```

### Obtaining Tokens

1. **Register**: Create a new account via `POST /auth/register`
2. **Login**: Get access tokens via `POST /auth/login`
3. **Refresh**: Use refresh tokens via `POST /auth/token`

## Response Format

All API responses follow a consistent structure:

```json
{
  "error": false,
  "errors": [],
  "data": { /* Response data */ },
  "message": "Success message",
  "status": 200
}
```

### Error Responses

```json
{
  "error": true,
  "errors": ["Error description"],
  "message": "Error message",
  "status": 400
}
```

## Pagination

List endpoints support pagination with the following parameters:

- `page`: Page number (default: 1)
- `limit`: Items per page (default: 10)

Paginated responses include:

```json
{
  "error": false,
  "data": [/* items */],
  "pagination": {
    "page": 1,
    "limit": 10,
    "total": 150,
    "count": 10
  }
}
```
