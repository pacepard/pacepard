# @pacepard/blocs

Block builder package for Pacepard.

## Installation

This package is part of the Pacepard monorepo and is automatically included in the workspace.

## Usage

```typescript
import { /* your exports */ } from '@pacepard/blocs'
```

## Development

This package uses:
- TypeScript with React library configuration
- ESLint with React internal rules
- Shared workspace configurations
